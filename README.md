# NVFCorpus [now under construction]

The Nonverbal Function Corpus (NVFCorpus) is a multimodal conversation dataset developed to investigate the multifunctional aspects of nonverbal behaviors of interlocutors in multiparty conversations. It centers on four-person consensus-building dialogues conducted among six mixed-gender groups. Each group comprises Japanese participants, with each individual engaging in four 10-minute sessions conducted in both face-to-face and remote settings. The total length of conversation sessions is 264 minutes. For the face-to-face sessions (125 minutes), the corpus includes manually annotated function labels for over 120 nonexclusive functions. These functions encompass head movements, facial expressions, gaze, and listener vocal backchannels (referred to as Aizuchi). Three external annotators conducted function labeling at the frame level.
